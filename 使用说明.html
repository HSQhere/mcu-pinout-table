使用说明

这个站点把常见 MCU 的引脚分布与功能复用关系做成可视化速查表。下面是查资料的方法、扩展芯片的步骤，以及数据字段的含义。

快速开始

全部页面都是纯静态文件，不需要安装任何东西，也不需要联网。

直接打开（最简单）

双击根目录的 index.html 即可。

用 file:// 方式打开时功能完全正常。唯一差别是浏览器出于安全策略不允许脚本读取本地 CSS 的规则列表，这不影响任何显示效果。

本地起服务（改代码时更方便）

如果要改样式或加芯片，起一个本地服务，改完刷新就能看到：

# 任选一种，在项目根目录执行
python -m http.server 8000
# 或
npx serve .

然后浏览器打开 http://127.0.0.1:8000/。

怎么用

页面按「首页 → 系列页 → 芯片详情页」三层组织。

首页与系列页

首页按芯片系列组织，目前两个系列：STM32（青绿）、ESP32（咖啡黄）。点卡片进入系列页。系列页列出该系列已收录的芯片，顶部搜索框可按型号、封装、关键词过滤（例如输入 F103、LQFP64、蓝桥杯、S3、QFN32）。

芯片详情页的四个板块

对应实际查资料时的四种场景：

板块用途
1 · 封装引脚分布图按真实封装四边排布（LQFP48/64/100、SMD-41 模组、QFN32），与实物引脚位置对应。点任一引脚，下方展开该脚的全部功能。
2 · 引脚功能总表每行一个引脚。搜索框支持型号、外设名、引脚号模糊搜索；下方按钮可按串口 / SPI / I2C / CAN / 定时器 / 调试等类别筛选。
3 · 常用外设引脚速查反查视角：想用某个外设，直接看它能挂在哪些引脚上。
4 · 硬件设计注意事项容易踩坑的点，例如 5V 容限、专用脚限制、BOOT 配置、内置 Flash/PSRAM 占用。

几个实用技巧

  • 引脚图上的颜色代表引脚类别：绿色 = 普通 GPIO，棕色 = 特殊功能脚，灰色 = 电源/地，紫色 = 调试口，灰褐 + 删除线 = 该型号上不可用（如被内置 PSRAM 占用）。图例在封装图下方，只显示当前芯片实际出现的类别。
  • 表格里不同颜色的功能名代表不同外设类别（串口蓝、SPI 绿、定时器橙、I2C 紫等），扫一眼就能区分。
  • 点引脚图上的引脚，会自动跳到总表对应行并高亮，两个板块是联动的。
  • 芯片页开头的三张卡片分别跳嘉立创商城（中文，可查价查库存）、原厂英文数据手册 PDF、原厂产品页。
  • 搜索框按 Esc 可快速清空。
  • 右上角图标可切换深色模式，选择会记住。
  • 手机或窄窗口下，封装图可左右滑动查看；表格也可横向滚动，表头会吸顶。

新增一颗芯片

关键设计：页面只有一个模板，芯片数据各自独立。 chip.html 不含任何具体芯片信息，它通过 URL 参数 ?id=f103c8t6 去注册表取数据再渲染。所以新增芯片不需要复制页面。

目录结构

MCU pinout table/ ├── index.html # 根入口：芯片系列列表 ├── assets/ │ ├── style.css # 全部样式（浅色/深色两套设计令牌） │ └── app.js # 全部逻辑：数据注册、渲染、搜索筛选、主题 ├── stm32/ │ ├── index.html # STM32 系列页 │ ├── chip.html # 芯片详情页模板（通过 ?id= 取数据） │ ├── 校准报告.md # 与官方手册的比对结果 │ └── data/ │ ├── f103c8t6.js # STM32F103C8T6 · LQFP48 │ ├── f407vet6.js # STM32F407VET6 · LQFP100 │ └── g431rbt6.js # STM32G431RBT6 · LQFP64 ├── esp32/ │ ├── index.html # ESP32 系列页 │ ├── chip.html # 芯片详情页模板（同上） │ └── data/ │ ├── esp32s3wroom1n16r8.js # ESP32-S3-WROOM-1-N16R8 · SMD-41 模组 │ └── esp32c3fh4.js # ESP32-C3FH4 · QFN32 裸片 ├── 使用说明.html └── README.md
  1. 新建数据文件

    在 stm32/data/ 下新建 你的芯片id.js，用 MCU.register({...}) 包住一个对象。MCU.register 会把它登记进注册表。

    MCU.register({
  id: "stm32h743vit6",          // URL 参数用，建议全小写
  name: "STM32H743VIT6",        // 页面大标题
  family: "STM32H7",            // 系列名
  pkg: "LQFP100",
  pkgSize: "14 × 14 mm",
  pitch: "0.5 mm",
  pinCount: 100,

  tags: ["高性能", "Cortex-M7"],
  spec: [
    ["内核", "Cortex-M7 @ 480 MHz"],
    ["Flash", "2 MB"],
    // ... 建议 8 条，页面上刚好排成 4 列两行
  ],
  intro: "一两句话说明这颗芯片的定位和典型用途。",

  source: {
    datasheet: "DS12110 Rev 8",
    refman: "RM0433 Rev 7"
  },

  // 手册与购买链接（芯片页开头显示）
  links: {
    stProduct:   "https://www.st.com/en/microcontrollers-microprocessors/stm32h743vi.html",
    stDatasheet: "https://www.st.com/resource/en/datasheet/stm32h743vi.pdf",
    lcsc:        "https://item.szlcsc.com/xxxxxxx.html"
  },

  pins: [
    {
      n: 1,                     // 引脚号
      nm: "PE2",                // 引脚名
      ty: "I/O FT",             // 类型：I/O、I、O、电源 S 等，FT 表示 5V 容限
      cat: "GPIO",              // 分类：GPIO / SPEC / PWR / DBG
      ds: "PE2",                // 复位后的默认功能
      af: {                     // 复用功能，按外设类别分组
        "SPI4": ["SPI4_SCK"],
        "TIM":  ["TIM3_ETR"],
        "SYS":  ["TRACECLK"]
      },
      ad: "SAI1_SD_A",          // 附加功能（可选）
      no: "上电时有短暂输出"     // 该脚的特殊注意事项（可选）
    }
    // ... 按引脚号顺序写全
  ],

  // 外设速查：想用某外设时，反查可用引脚
  periph: [
    {
      title: "USART1",
      rows: [
        ["TX", ["PA9", "PB6"]],
        ["RX", ["PA10", "PB7"]]
      ]
    }
  ],

  // 硬件设计注意事项，支持 <b> 加粗、<u> 强调、<br> 换行
  notes: [
    "VDDA 与 VREF+ 需<b>独立滤波</b>，不要直接连数字 3.3V。",
    "PC13–PC15 由电源开关供电，<u>不可作为电流源</u>。"
  ]
});
  2. 在系列页引入

    编辑 stm32/index.html，在文件底部按同样格式加一行：

    <script src="data/stm32h743vit6.js"></script>
  3. 完成

    刷新页面，系列页会自动多出一张卡片，详情页通过 stm32/chip.html?id=stm32h743vit6 访问。不需要改任何 JS 或 CSS。

新增一个系列（非 STM32）

esp32/ 就是照这套步骤接进来的完整范例，可以直接照着改。

  1. 新建文件夹

    例如 esp32/。

  2. 复制页面模板

    复制 stm32/index.html 和 stm32/chip.html 过去，../assets/ 路径保持不变即可（都在同一层）。再把两个文件的 <html> 加上 data-series="新系列名"（ESP32 用的是 data-series="esp"）。

  3. 放数据

    新建 esp32/data/ 放该系列芯片数据，并在两个 HTML 底部按序引入。

  4. 挂到首页

    在根 index.html 的 #series 区加一张卡片链过去。

  5. 加配色

    在 assets/style.css 里为该系列加一段配色变量（见下面「配色系统」）。

样式和逻辑完全复用，不用重复写。

数据字段说明

cat — 引脚分类（决定封装图配色）

值含义颜色
GPIO普通可编程 IO绿
SPEC特殊功能脚（OSC、BOOT、NRST、VBAT、EN 等）棕
PWR电源与地灰
DBG调试口（SWD / JTAG）紫
NC不可用 / 被内置 Flash、PSRAM 占用灰褐 + 删除线

af 的键名

决定表格里功能名用什么颜色。已支持：UART、SPI、I2C、CAN、USB、TIM、ADC、DAC、COMP、SAI、DBG、SYS、REMAP、DMA、FSMC、ETH、DCMI、SDIO、RTC、TOUCH、CLK、FLASH、STRAP。

写其它名字也能正常显示，只是用默认颜色；筛选按钮会自动从数据里收集实际出现的类别，不需要手工维护。

layout 与 epad — 非四边均分封装

STM32 的 LQFP 四边引脚数基本均分，程序会自动推算。但 ESP32-S3-WROOM-1 这种模组（左 14 / 底 13 / 右 13 / 顶 0）或 QFN32，必须显式给出真实布局：

layout: {
  left:   [1, 2, 3, 4, 5, 6, 7, 8],         // 左侧自上而下
  bottom: [9, 10, 11, 12, 13, 14, 15, 16],  // 底边自左向右
  right:  [24, 23, 22, 21, 20, 19, 18, 17], // 右侧自下而上
  top:    [32, 31, 30, 29, 28, 27, 26, 25]  // 顶边自右向左
},
epad: {n: 33, nm: "GND", desc: "底部散热焊盘 · 接地"},

epad 是底部散热焊盘，会单独画在芯片本体中央，点击同样能看详情。

links — 手册与购买入口

芯片页开头三张卡片就来自这里。ST 芯片用 stProduct / stDatasheet；其它厂商用 vendor + vendorProduct + vendorDatasheet（vendor 同时决定页面显示「乐鑫 Espressif」还是「ST 官方」）：

links: {
  vendor: "乐鑫 Espressif",
  vendorProduct:   "https://www.espressif.com/en/products/socs/esp32-c3",
  vendorDatasheet: "https://www.espressif.com/sites/default/files/documentation/esp32-c3_datasheet_en.pdf",
  lcsc:            "https://item.szlcsc.com/3060870.html"
}

ty — 引脚类型

按数据手册的 Type + I/O structure 两列合并书写，例如：

  • I/O — 普通双向
  • I/O FT — 5V 容限
  • I/O TTa — 3.3V 容限且带模拟功能
  • I / O — 仅输入 / 仅输出
  • S — 电源
这一列务必按手册填准，它是判断能不能直接接 5V 器件的关键依据。本站校准时就发现过 5V 容限被误标的引脚。

设计约定

  • 配色：分两层。主页是白/米色中性底 + 墨灰强调色；每个系列用自己的强调色（STM32 青绿、ESP 咖啡黄）。正文对比度按 WCAG AA 校核，浅色与深色两套主题共 14 个页面组合全部达标。
  • 响应式：320px–1400px 无横向溢出、无文字截断；封装图与表格在窄屏内可横向滚动，不撑破页面。
  • 数据驱动：所有芯片内容都在 data/*.js，页面模板不含硬编码信息。

配色系统

配色由两层变量叠加决定：表层（底色 / 文字 / 分隔线）和强调色（按钮、标签、色条）都按系列分组，再由主题决定明暗。

系列底色强调色说明
主页（默认）#f7f6f2 白米#5c6672 墨灰中性，不抢系列色
data-series="stm32"#f0f2ed 淡绿#3f7266 青绿STM32 系列页与芯片页
data-series="esp"#faf7ef 米黄#8a6a30 咖啡黄ESP32 系列页与芯片页

切换系列配色只需在页面根元素上加一个属性：

<!-- 主页：不写 data-series，用中性墨灰 -->
<html lang="zh-CN">

<!-- STM32 系列页：青绿 -->
<html lang="zh-CN" data-series="stm32">

<!-- ESP32 系列页：咖啡黄 -->
<html lang="zh-CN" data-series="esp">

单张卡片想局部套用某个系列色，加 .palette-green / .palette-coffee / .palette-slate 工具类即可 —— 主页的系列卡片就是这么给卡片顶端色条和「配色」胶囊上色的。

新增一个系列配色：在 assets/style.css 里照抄一段，改三个选择器（[data-series="新系列"]、[data-theme="dark"][data-series="新系列"]、可选的 .palette-新系列），然后页面根元素加对应属性。

数据可信度

STM32 三颗芯片的引脚定义、引脚类型、复用功能已与 ST 官方 PDF 数据手册逐条比对，共修正 19 处错误，详细记录见 校准报告。
ESP32 两款（ESP32-S3-WROOM-1-N16R8、ESP32-C3FH4）的引脚定义、类型、默认功能、复用功能、strapping 脚与内置 Flash / PSRAM 占用情况全部取自乐鑫官方手册，四边引脚布局按手册封装图逐一核对。

尚未覆盖：STM32 复用功能的 AF0–AF15 编号、电气参数（绝对最大额定值、灌拉电流）、勘误表（Errata）；ESP32 的 GPIO Matrix 任意映射关系、IO MUX 的 F0–F4 功能编号。做正式设计时请以手册原件为准。

常见问题

为什么某颗芯片的某个外设引脚比手册少？

已按当前封装剔除未引出的引脚。例如 STM32 LQFP100 封装没有 PF/PG 端口，相关复用功能不会列出，页面里的说明文字会标注「属 LQFP144+ 封装」。ESP32-S3-WROOM-1-N16R8 内置 8 MB 八线 PSRAM，IO35 / IO36 / IO37 被占用，页面上标为「不可用」并加删除线。

搜索不到某个功能？

搜索是基于表格文本的模糊匹配，可以试外设名（usart1）、引脚名（PA9 / IO4）、引脚号（42）或功能片段（rmii / adc2）。也确认一下该功能在当前封装上是否真的引出。

颜色看着不对 / 想换配色？

所有颜色都是 assets/style.css 顶部的 CSS 变量（设计令牌）。表层色与强调色按系列分组（[data-series="..."]），深色在 [data-theme="dark"] 块里覆盖，改对应系列那一组即可。

能加别的厂商芯片吗？

可以。数据结构是通用的，按上面「新增一个系列」的步骤操作即可，cat / af 键名沿用现有约定就能直接复用配色。ESP32 就是照这个流程接进来的第二个系列。
