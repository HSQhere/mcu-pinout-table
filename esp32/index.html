模组与裸片不是一回事

ESP32-S3-WROOM-1 是模组：41 个焊盘，含 3.3V、EN、天线与内置 Flash / PSRAM。ESP32-C3FH4 是裸片：QFN32，引脚就是芯片引脚，需要自己画晶振、匹配网络与电源。

怎么用

点引脚图上的任一引脚可查看完整复用清单；总表支持引脚名 / 外设 / 引脚号模糊搜索，也可按串口、SPI、ADC、启动配置等快速筛选。

哪些引脚不能碰

ESP32 与 STM32 最大的差别是：内置 Flash / PSRAM 会占用引脚。S3 的 IO26–IO37、C3 的 GPIO12–GPIO17 都不能外用；S3 的 IO35–IO37 在带 Octal PSRAM 的模组（如本页的 N16R8）上直接不可用，已在引脚图与总表里标为「不可用」。
