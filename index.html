引脚类型速查

总表里的类型列沿用手册写法，接线前先认准这几种：

  • I/O 普通数字输入输出
  • I/O FT 5V 容限，可直连 5V 逻辑
  • I/O TTa 3.3V 容限 + 模拟功能
  • S 电源脚（VDD / VSS / VDDA）
  • NRST 复位脚，内部上拉

不带 FT 的引脚接 5V 会损坏芯片；ESP32 全系列都不耐 5V。
